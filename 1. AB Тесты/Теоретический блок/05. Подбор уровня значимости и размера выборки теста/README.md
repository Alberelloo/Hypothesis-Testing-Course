# Занятие 05 — Подбор уровня значимости и размера выборки теста

## Обзор
По умолчанию везде используют $\alpha$ = 0.05 и соответственный размер выборки, но чем это обосновано ? Может стоит каким-то образом подбирать под каждый эксперимент свой уровень значимости и размер выборки ? Урок посвящен рассмотрению подбора этих параметров на основе оптимизации ROI теста. 

## Цели занятия
- Изучить фреймворк для расчёта **оптимальных** значений $\alpha$ и $n$ (размер выборки), максимизирующих ожидаемую прибыль (ROI) от тестирования. 
- Научиться не бояться выставлять $\alpha$ более 0.05, изучив несимметричность функции мощности.

# Сайт курса

Сайт собирается из README и ноутбуков репозитория (MkDocs Material + mkdocs-jupyter) и публикуется на GitHub Pages. Исходники занятий для сайта не копируются и не правятся: скрипт `build_site.py` собирает временную папку `site_build/`, которую не нужно коммитить.

## Что делает скрипт
- обходит модули, находит занятия (`lecture.ipynb`, `practice.ipynb`) и их README;
- в начало страницы добавляет заголовок, паспорт занятия, обзор и цели из README (если в ноутбуке их нет), для практик ещё и кнопку «Открыть в Colab»;
- скрытые решения практик превращает в раскрывающиеся блоки, в конец добавляет источники из README;
- ссылки на другие занятия внутри текста заменяет на ссылки внутри сайта;
- пишет `mkdocs.yml` с навигацией по структуре папок: новое занятие появляется на сайте само.

## Локальная сборка
```
pip install -r site/requirements.txt
python site/build_site.py
mkdocs build -f site_build/mkdocs.yml -d ../site_out
```
Готовый сайт окажется в `site_out/`. Для просмотра: `python -m http.server -d site_out`. Сборка занимает около минуты.

## Публикация
Файл `.github/workflows/pages.yml` собирает и публикует сайт после каждого слияния в `main`. Один раз нужно включить в настройках репозитория Settings → Pages → Source: GitHub Actions.

# Занятие 11 — Мета-лернеры

## Обзор
Продолжение темы потенциальных исходов сосредоточено на применении методов машинного обучения для оценки причинных эффектов: разные виды meta-learner подходов

## Цели занятия
- Освоить принципы ML-оценок в causal inference и понять, чем они отличаются от базовых методов.
- Разобраться в meta-learner стратегиях (S-, T-, X-learner) и условиях их применения.

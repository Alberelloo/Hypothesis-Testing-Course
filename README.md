# Hypothesis Testing Course

- Курс даёт **обзорное** представление о методологиях тестирования продуктовых гипотез: от классического A/B теста до причинного анализа без эксперимента.
- Материалы собраны из открытых источников и структурированы как учебный план.
- Предполагается наличие [предварительных знаний](#предварительные-требования).

## 🎯 Для кого этот курс?
Курс рассчитан на тех, кто принимает или обосновывает решения по результатам экспериментов: аналитиков и data scientists (и тех, кто только начинает, и тех, у кого уже есть опыт), а также продуктовых менеджеров и тимлидов, которым нужно понимать, чему можно верить в отчётах по тестам.

Единого пути для всех нет. Занятия не обязательно проходить подряд: ниже [маршруты](#-маршруты-обучения) под разные задачи, а полная программа ниже остаётся оглавлением.

### Маршрут 1. Базовый A/B

**Кому:** Вы только начинаете работать с экспериментами или хотите упорядочить базу.

**Нужно знать заранее:** базовые знания статистики и Python (см. [требования](#предварительные-требования))

### Маршрут 2. Надёжность и скорость теста

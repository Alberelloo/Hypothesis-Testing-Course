# Hypothesis Testing Course

- Курс даёт **обзорное** представление о методологиях тестирования продуктовых гипотез.
- Материалы собраны из открытых источников и структурированы как учебный план.
- Предполагается наличие [предварительных знаний](#предварительные-требования).

## 🎯 Для кого этот курс?
Целевая аудитория:
- Студенты бакалавриата и магистратуры, связанные с аналитикой данных и data science.
- Начинающие product/data analysts и data scientists.
- Специалисты, работающие с A/B-тестами и решениями на основе данных.

## 🏆 Что вы узнаете?
После прохождения курса вы сможете:
1. Грамотно планировать запуск A/B-тестов и квазиэкспериментов.
2. Корректно анализировать и защищать результаты экспериментов.
3. Использовать альтернативные дизайны для нестандартных сценариев.

## 🗂️ Программа курса

Курс состоит из 3 больших модулей, каждый из которых имеет как теоретическую, так и практическую части. Дополнительно к каждой части предлагается кейс для проверки качества усвоения материала.

Номер занятия записывается как `<модуль>.<занятие>` (например, 1.02), практические занятия — как `<модуль>.П<номер>`.

Статусы: ✅ готово · 🛠 есть, но требует доработки · 🚧 в разработке.

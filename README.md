# Hypothesis Testing Course

Обзорный курс по методологиям тестирования продуктовых гипотез: от A/B тестов до квази-экспериментов и causal inference. Материалы собраны из открытых источников и структурированы как учебный план: теория в ноутбуках, практика на Python.

**Объём:** 3 модуля, ~48 часов (теория + практика).

## 🎯 Для кого этот курс?
- Студенты бакалавриата и магистратуры, связанные с аналитикой данных и data science.
- Начинающие product/data analysts и data scientists.
- Специалисты, работающие с A/B-тестами и решениями на основе данных.

**Предварительные требования:** базовая статистика (меры центральной тенденции, распределения, тестовые статистики), Python на уровне чтения и написания кода, базовое машинное обучение.

## 🏆 Что вы узнаете?
- Грамотно планировать запуск A/B-тестов и квазиэкспериментов.
- Корректно анализировать и защищать результаты экспериментов.
- Использовать альтернативные дизайны для нестандартных сценариев.

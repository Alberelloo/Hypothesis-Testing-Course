# Hypothesis Testing Course

- Курс даёт **обзорное** представление о методологиях тестирования продуктовых гипотез: от классического A/B теста до причинного анализа без эксперимента.
- Материалы собраны из открытых источников и структурированы как учебный план.
- Единого пути для всех нет: занятия не обязательно проходить подряд, ниже — [пути под разные задачи](#-для-кого-этот-курс).

## 🎯 Для кого этот курс?

Номера занятий задают структуру курса, а не порядок изучения. В колонке «Путь» занятия идут в рекомендуемом порядке с учётом зависимостей. Название занятия по номеру можно найти в [программе курса](#️-программа-курса).

| Группа | Для кого | Пререквизиты | Вы научитесь | Путь | Время |
|---|---|---|---|---|---|
| 🌱 **Первый A/B тест** | Студенты и джуниор-аналитики, которые ещё не запускали тесты | • статистика: распределения, ЦПТ, ДИ<br>• Python: numpy, pandas, scipy | • планировать тест: метрики, MDE, выборка<br>• считать эффект с ДИ, в том числе для ratio-метрик<br>• работать с несколькими метриками<br>• ускорять тест (CUPED) | 1.01 → 1.02 → 1.П1 → 1.03 → 1.П2 → 1.04 | 10,5 ч |
| 🛡 **Надёжные тесты** | Аналитики, которые уже запускают тесты и хотят доверять результатам | • группа «Первый A/B тест» или эквивалентный опыт | • подбирать α и размер выборки под цену ошибки<br>• видеть ловушки малой мощности (ошибки S и M)<br>• смотреть тест по ходу без роста ложных срабатываний<br>• сводить результаты тестов в мета-анализ | 1.05 → 1.06 → 1.07 → 2.01 → 2.П1 → 3.01<br>*опционально:* 2.04, 2.05 (+3 ч) | 10 ч<br>(20,5 с нуля) |
